# docs/brand

Brand assets for SboxServerConsole.

- `sboxserverconsole-icon.png` — the badge: a terminal prompt inside an open
  bracket frame, on a dark disc. Transparent outside the disc.
- `sboxserverconsole-lockup.png` — the badge plus the wordmark, for README
  headers and anywhere with horizontal room. The wordmark is white with a
  near-black outline, so it holds on a light page and on a dark one.
- `sboxserverconsole-mark.svg` — the flat mark: the bracket frame and the screen
  panel removed and the field inverted to blue, so the prompt still reads at
  16-32px. This is what the dashboard uses as its favicon.

SboxServerConsole is a community project. Nothing here reproduces Facepunch or
s&box branding; the blue is the only thing the palette borrows.
